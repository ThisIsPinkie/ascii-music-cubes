# 🎵 Music Cube — ASCII Audio Visualizer

Три ASCII-куба, которые реагируют на системный звук в реальном времени.
Левый — бас, центр — середина, правый — высокие частоты.

## Что умеет

- 🎨 Три куба со своими цветами и диапазонами
- 🔊 Захват системного звука (WASAPI Loopback)
- 📊 Спектр из 40 полос
- 💥 Вспышка на бит
- 📏 Толщина рёбер растёт от громкости

## Установка

```bash
pip install pygame-ce numpy PyAudioWPatch

## Что на экране

- **Слева** — куб баса (оранжевый)
- **Центр** — куб середины (изумрудный)
- **Справа** — куб высоких частот (неоновый)
- **Внизу** — спектр из 40 полос
- **Сверху** — HUD с уровнями

## Настройки

В `music_cube_trio.py` можно менять:

- `FPS` — кадров в секунду (60 / 120)
- `THICKNESS_MAX` — толщина рёбер (0/1/2)
- `BEAT_THRESHOLD` — чувствительность к биту
- `FIXED_ZOOM` — размер кубов
- `NUM_BARS` — количество полос спектра

## Требования

- Windows 10/11 (WASAPI Loopback)
- Python 3.11+
- Динамики или наушники (не Bluetooth — loopback не работает)
- Разрешение микрофона/звука в системе
